# ⚡ UI-vik (Visual-Increment-Kit)

A high-performance, visually immersive New Tab dashboard for Chrome, engineered with **Manifest V3**. UI-vik transforms your browser into a tactical command center or a sleek executive suite using modular widgets and dynamic theme architectures.[cite: 2]

---

## 🎨 Choose Your Interface

### 🕹️ Gaming (HUD)
A high-intensity, tactical HUD designed for gamers.
*   **Aesthetic:** Chamfered glass edges, glowing cyan borders, and "Alert Red" hardware accents.[cite: 1]
*   **System Status:** Live network diagnostics (Ping & Download speed) integrated into the clock.
*   **Arsenal:** Quick Launch shortcuts for Steam, Discord, and tactical game trackers.
*   **Boot Sequence:** Geometric "HUD Scan" initialization animation.

### 💼 Professional
A minimalist, high-contrast dashboard for deep work.
*   **Aesthetic:** Solid charcoal glass, pristine white typography, and sleek rounded containers.[cite: 1]
*   **Executive Player:** A studio-grade media controller with high-contrast playback logic.
*   **Uniform Layout:** Fixed-size widgets with custom minimalist scrollbars for a clean grid.
*   **Boot Sequence:** Buttery-smooth fade and aperture expansion.

---

## 🚀 Core Features

*   **Modular Widget System:** Toggleable Quest Tracker (To-Do), Strategy Log (Notes), and Active Metrics (Stats).[cite: 2]
*   **Cyber-Search Terminal:** Intelligent autocomplete powered by DuckDuckGo, hidden behind a double-click gesture for maximum focus.
*   **Adaptive Media Hub:** Real-time playback tracking from YouTube/Spotify with a 10-track session history.[cite: 2]
*   **Smart Backgrounds:** Support for local video uploads, image slideshows, and interactive parallax effects.[cite: 2]
*   **Dynamic Branding:** Official browser-specific favicons that adapt whether you are on Chrome, Edge, or Brave.

---

## 🛠️ Technology Stack

*   **Core:** Vanilla JavaScript (ES6+ Modules)[cite: 2]
*   **APIs:** Chrome Extension API (Storage, Scripting, TopSites, Manifest V3)[cite: 2]
*   **Styles:** Advanced CSS3 (Custom Properties, Clip-paths, Keyframe Animations)
*   **Data:** Local/Sync storage for cross-device preference persistence.[cite: 2]

---

## 📥 Installation

1.  Clone this repository.
2.  Open `chrome://extensions/` in your browser.
3.  Enable **Developer Mode**.
4.  Click **Load unpacked** and select the project folder.

---

## 🔧 Configuration

Access the **Spectrum Lab** (Settings Panel) via the gear icon to:
*   Adjust **Blur Intensity** and **Overlay Opacity**.[cite: 2]
*   Define custom **Accent Colors** across the entire UI spectrum.[cite: 2]
*   Manage widget positions and search engine preferences.[cite: 2]
